PACOTE DE SÍMBOLOS DO RULEBOOK MIDDARA
Catálogo e vetores exportados do catálogo semântico do projeto.

CONTEÚDO DO ZIP
- 63 arquivos SVG em /svg, incluindo variantes de desenho e localização.
- 41 IDs semânticos no catálogo; consulte manifest.csv para os nomes de arquivo, categorias e páginas de origem.
- catalogo-completo.pdf: pranchas de consulta visual em tamanho ampliado.
- README.txt: este guia, em formato simples que abre no Bloco de Notas do Windows.

TRANSPARÊNCIA E FIDELIDADE
- Nos SVGs vetoriais, a área fora dos desenhos é transparente. Não há uma caixa branca atrás dos círculos.
- Áreas brancas que formam o desenho (por exemplo, a lâmina dentro do círculo preto) são tinta do próprio símbolo.
- Dois itens usam imagem raster incorporada: token.blue-totem e a variante combat.skull--bounty-red-raster.svg. Veja o catálogo/manifesto antes de escolher essas versões.
- O pacote guarda os desenhos e as variantes; não guarda posição/baseline, avanço tipográfico ou escala de cada ocorrência no PDF.

COMO USAR
- Illustrator, CorelDRAW e Inkscape: abra o SVG para editar os caminhos vetoriais.
- InDesign: use Arquivo > Inserir/Place para colocar o SVG no layout.
- Photoshop pode rasterizar o SVG conforme a opção de abertura/importação. Guarde o SVG original para manter a fonte vetorial.
- O prefixo/nome antes de “--” é o ID semântico. Um sufixo depois de “--” indica uma variante específica; preserve o arquivo da variante quando precisar reproduzir aquela aparência.
- O fundo quadriculado aparece somente nas pranchas de prévia para mostrar transparência; não está dentro dos SVGs vetoriais.
- Os cinco SVGs attack.melee, attack.ranged, attack.melee-ranged, weapon.hand.one e weapon.hand.two têm grupos nomeados para edição. Nas mãos, o número é um glifo vetorial separado do pictograma, como no PDF.
- Um halo fino visto em captura ampliada/reduzida é antialiasing da rasterização de prévia. Não remova nem acrescente contorno/fundo ao SVG por causa disso; o arquivo vetorial não contém essa caixa.
