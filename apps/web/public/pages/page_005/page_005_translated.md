double-sided Terrain tokens

and Terrain Pg. 21.

double-sided **Terrenos** **Ficha**s

unpredictability to Encounters. 

Each Encounter will dictate 
which **Terrenos** **Ficha**s are needed, 
Otherwise, these **Ficha**s can be 
kept in the game box. These **Ficha**s 
come in a variety of sizes such as 
1x1 inch and 2x1 inch. See **Peças**

rule. See Effect Tokens Pg. 95.
